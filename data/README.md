# Data

- `train.csv` — 25,247 labelled customers, 19% default rate
- `validate.csv` — unlabelled holdout for scoring

Source: FinClub open project dataset, IIT Roorkee. Schema follows the
UCI "default of credit card clients" convention: six months of billing
(`Bill_amt1-6`), repayment (`pay_amt1-6`) and repayment-status codes
(`pay_0`, `pay_2-6`).
